# Code of Conduct / Davranış Kuralları

PTCalc is a small open-source project maintained by a single academic author. Everyone who takes part in it,
whether by opening an issue, sending a pull request, reviewing code or discussing methods, is expected to keep
the following standards. They apply in the GitHub repository, in e-mail about the project and anywhere else the
project is represented.

## Our standards

- Be respectful and constructive. Criticise methods, code and results, not people.
- Assume good faith. Contributors come from pharmacy, chemistry, statistics and software backgrounds; a question
  that seems basic in one field is not in another.
- Give credit. When a contribution builds on published work or someone else's data, cite it.
- Be honest about results. This project compares itself with other software (for example DDSolver); comparisons
  are stated as comparisons, never as claims of superiority, and limitations are reported.
- Respect privacy. Do not post other people's unpublished data, e-mail addresses or personal details.

Unacceptable behaviour includes insults, discriminatory or sexualised language, personal attacks, harassment in
any form, and publishing private information without permission.

## Enforcement

Reports may be sent in confidence to the maintainer at mali.ege@rxmediapharma.com.tr. The maintainer will
review every report, may remove comments, commits or contributions that violate these standards, and may
temporarily or permanently exclude a contributor from the project. Reporters' identities are not disclosed
without their consent.

## Attribution

These rules are adapted in spirit from the Contributor Covenant, version 2.1
(<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>), shortened for a single-maintainer
project.
